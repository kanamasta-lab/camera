# Cozy Lens — GitHub Pages

Version statique : aucun npm, React ou Vite nécessaire. Elle fonctionne directement sur GitHub Pages.

## Installation
1. Remplacer les fichiers de votre dépôt par le contenu de ce dossier.
2. GitHub → Settings → Pages → Deploy from branch → choisir la branche et `/ (root)`.
3. Attendre le déploiement puis ouvrir l'URL Pages.

La caméra demande une permission HTTPS. Les fonctions zoom/torch dépendent du navigateur et du téléphone.
